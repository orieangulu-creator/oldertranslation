# 需补充的图标资源（在 DevEco Studio 中添加）

ArkTS 代码引用了以下 media 资源，请在此目录放入对应 PNG（建议 192×192，单色填充图标，配合 fillColor 变白）：

| 资源名 | 用途 |
|---|---|
| `app_icon.png` | 应用图标 / 启动图标 |
| `ic_listen.png` | 首页"听"——大耳朵图标 |
| `ic_speak.png` | 首页"说"——大嘴巴图标 |
| `ic_photo.png` | 首页"拍"——大相机图标 |
| `ic_sos.png` | 首页"应急求助"——SOS 图标 |

> 占位说明：仓库未提交二进制图标。首次用 DevEco 打开工程时补齐上述文件即可编译运行。
